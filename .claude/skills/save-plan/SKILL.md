# Save Plan to Workplan

Copy the current plan from this session to `.claude/work-plan.md`.

## Instructions

Take whatever plan exists in the current conversation context and write it word-for-word to `.claude/work-plan.md`, replacing any existing content.

If no plan exists in the current session, inform the user that there is no plan to save.
